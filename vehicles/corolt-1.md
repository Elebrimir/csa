# 🚀 Llançador Suborbital: Corolt-I (CSA-01)

> *"El primer pas cap a l'espai de la Corolt Space Agency."*

![Corolt-I Blueprint](../assets/vehicles/corolt-1_blueprint_1.png)

---

## 📐 Especificacions Tècniques

| Paràmetre | Valor d'Enginyeria |
| :--- | :--- |
| **Fabricant** | Corolt Space Agency (CSA) |
| **Tipus de Vehicle** | Coet Sonda Suborbital Monocilíndric (Sounding Rocket) |
| **Diàmetre** | 0.35 m |
| **Massa Total al Llançament** | 0.283 t (283 kg) |
| **Massa en Sec (Sense combustible)** | 0.153 t (153 kg) |
| **Propulsió** | 1x Motor Sòlid SRM-L (*Sounding Rocket Motor*) |
| **Empenta (Thrust)** | 7.500 kN |
| **Ràtio Empenta/Pes (TWR)** | 2.80 (Inici) $\rightarrow$ 5.00 (Fi d'etapa) |
| **Delta-v ($\Delta v$)** | ~800 m/s (Nivell del mar) / ~940 m/s (Buit) |
| **Temps de Combustió** | 25.9 segons |
| **Estabilització** | 4x Aletes aerodinàmiques radials |
| **Recuperació** | Paracaigudes de càrrega miniatura (Pack Chute) |

---

## 🔬 Càrrega Útil & Instrumentació Científica
* **Computadora de Bord**: Unitat de telemetria i dades Kerbalism.
* **Potència Elèctrica**: Bateria miniatura integrada per a suportar la transmissió de dades.
* **Objectiu Operatiu**: Registrar el perfil de densitat atmosfèrica, temperatura i radiació de fons fins a assolir l'apogeu.
