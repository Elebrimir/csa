# 🚀 Suborbital Launcher: Corolt-I (CSA-01)

> *"The first step into space for the Corolt Space Agency."*

## 📐 Technical Specifications

| Parameter | Engineering Value |
| :--- | :--- |
| **Manufacturer** | Corolt Space Agency (CSA) |
| **Vehicle Type** | Single-Stage Suborbital Sounding Rocket |
| **Diameter** | 0.35 m |
| **Gross Launch Mass** | 0.283 t (283 kg) |
| **Dry Mass (Burnout)** | 0.153 t (153 kg) |
| **Propulsion** | 1x Solid Rocket Motor SRM-L (*Sounding Rocket Motor*) |
| **Thrust** | 7.500 kN |
| **Thrust-to-Weight Ratio (TWR)** | 2.80 (Liftoff) $\rightarrow$ 5.00 (Burnout) |
| **Delta-v ($\Delta v$)** | ~800 m/s (Sea Level) / ~940 m/s (Vacuum) |
| **Burn Time** | 25.9 seconds |
| **Stabilization** | 4x Fixed radial aerodynamic fins |
| **Recovery System** | Miniature cargo parachute (Pack Chute) |

---

## 🔬 Scientific Payload & Instrumentation
* **Flight Computer**: Onboard Kerbalism telemetry recorder and avionics unit.
* **Electrical Power**: Integrated miniature battery supporting telemetry streaming.
* **Mission Goal**: Record atmospheric density profiles, ambient temperature, and cosmic radiation background up to apogee.
